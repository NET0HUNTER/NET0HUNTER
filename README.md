### 🛡️ Core Expertise & Engineering Focus

- **Enterprise ERP Systems**: Architecture, multi-tier phase budgeting, labor variance analysis ($H_P - H_A$), financial audits, and automated billing engines.
- **Cybersecurity & Defense**: Zero-trust architecture, PyCryptodome AES-256-GCM column encryption, Ed25519 cryptographic key management, UFW firewall design, Fail2ban intrusion prevention, and systemd socket mitigation.
- **Data Engineering**: PostgreSQL 16 loopback isolation (`127.0.0.1:5432`), SQLite atomic crash-consistent online backup pipelines, and native SSH tunnel administration.
- **Executive Reporting**: Programmatic vector PDF generation (ReportLab with custom embedded typography) and executive Excel (.xlsx) engines with native formulas.
